# RP-Pi-PICO
Raspberry Pi RP2040W

## Study tools

- [RP2040 Peripherals for Dummies](https://allwyn3t6.github.io/RP-Pi-PICO/peripherals-for-dummies/): ten peripherals in plain language, with simulators
- [RP2040 Practice Lab](https://allwyn3t6.github.io/RP-Pi-PICO/practice-lab/): self-paced practice game with score sheet
- [PIO for Dummies](https://allwyn3t6.github.io/RP-Pi-PICO/pio-for-dummies/): learn the RP2040's Programmable I/O from logic gates and 3D state machines to writing PIO programs, with a simulator and 8 missions
