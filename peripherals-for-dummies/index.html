How to use this guide

A peripheral is a helper circuit built into the RP2040 chip. Each one does a single job (keeping time, measuring a voltage, talking to a sensor) so your program does not have to. Learn them one by one, in this order:

  1. Pick a helperStart with helper 1 (Timer) and work down the list of helpers. It goes from easiest to hardest. You can also tap any box on the chip picture.
  2. 1 · UnderstandRead the one-line summary and the “Picture this” story. Then press Next through four short steps while the diagram lights up. Open the Jargon buster if a word is new.
  3. 2 · PlayDo the three “Try this” tasks in the simulator and tick them off. Break things on purpose: that is how you learn what failure looks like.
  4. 3 · Real lifeSee where the helper is used in medical devices, which Pico pins to wire, and the mistakes beginners usually make.
  5. 4 · CodeCopy the short program into Thonny or a Wokwi Pico project. Change one number, guess what will happen, then run it.
  6. 5 · Check yourselfAnswer the three questions. Wrong answers just ask you to try again. When all three are right, the helper is done.
Three dots = doneEach helper in the list has three dots: Understand, Play and Check yourself. All three green means that helper is complete.

Teacher’s notes
  1. Share this link with the class: students need nothing but a browser. It works on phones.
  2. In a lab hour, do one helper together: read the story aloud, run the simulator on the projector, then let students finish Play and Check yourself alone.
  3. For homework, set two helpers and ask for a screenshot of the three green dots, or of the badge at the end.
  4. Pair each helper with a Wokwi build using the snippet in the Code tab (for example, PWM with a servo on GP15).
  5. This page does not send scores anywhere. For graded revision with a score sheet, use the RP2040 Practice Lab.
